# Round type: build

A question about **building a product or feature**: what to build, how, and in what order.
Each role uses the lens in its own agent file. Phasing in Recommendation: **MVP / later / not
building**. Also answer this type's checklist: [checklist.md](checklist.md).

Default roles: product-designer, ux-researcher, market-researcher, ranking-engineer, architect,
data-scientist, data-engineer (up to 3 per round).
